# Data Intake Record

## Project brief
Analyze customer purchasing behavior and develop a prototype to predict
repeat purchases within the next 30 days.

## Engagement
Independent portfolio project simulating a client engagement.
The dataset is public and was not supplied by a paying client.

and a repeat-purchase prediction prototype.
